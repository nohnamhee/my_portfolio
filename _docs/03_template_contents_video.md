# 영상 프로젝트 템플릿 (Contents · BX 전용)

이 양식은 모바일 형태의 세로형 영상이나 콘텐츠를 보여주기 위해 특별히 제작된 템플릿입니다.

---

## 1. 기본 정보 (Left Panel)
- **카테고리 (Category):** Contents · BX
- **프로젝트명 (Title):** [예: Short-form Video Contents]
- **프로젝트 설명 (Description):** [예: 인스타그램 릴스 및 쇼츠용으로 기획된 세로형 영상 콘텐츠입니다...]
- **사용 툴 (Tools):** [예: Premiere Pro, After Effects]
- **작업 연도 (Year):** [예: 2026]

## 2. 모바일 디바이스 레이아웃 특징 (Right Panel)
이 템플릿은 우측 영역에 **아이폰 모양의 모바일 디바이스 프레임 3개**가 나란히 들어가는 형태를 기본으로 합니다.

- **디바이스 규격:** `452px * 783px` (비율 유지)
- **배열:** 1열에 3개의 디바이스 나열
- **간격(Gap):** 디바이스 사이 `6.25vw` 간격
- **리듬감 있는 배치:** 2번째(중앙) 디바이스는 양쪽보다 **30% 아래로 내려가게 배치 (transform: translateY(30%))**
- **외곽선(Border):** 전체 웹사이트에서 사용하는 기본 구분선(`var(--border)`) 적용
- **라운드(Border-radius):** 모바일 룩앤필을 위한 `24px` 둥근 모서리 적용
- **그림자(Shadow):** `-17px 24px 30px 0px rgba(0,0,0,0.2)`

## 3. 🖼️ 리소스 가이드

해당 템플릿을 생성하려면 프로젝트 폴더 안에 다음 파일들을 준비해 주시면 됩니다.
1. `thumb.jpg` (또는 png) : 메인 갤러리 썸네일
2. `video_01.mp4` / `video_02.mp4` / `video_03.mp4` : 디바이스 프레임에 들어갈 실제 영상 소스들 (혹은 `.jpg` 포스터 이미지)

---

**💡 사용 방법:** 
위 내용을 복사한 뒤, 대괄호 `[...]` 안의 내용을 채워서 **"이 내용으로 영상 템플릿 프로젝트 만들어줘"** 라고 말씀해주세요!
미리 작성된 `.contents-video-grid` 및 `.video-device` CSS 클래스를 기반으로 완벽한 레이아웃을 구성해 드립니다.
