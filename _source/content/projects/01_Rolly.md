# 새 프로젝트 추가 템플릿

이 양식을 복사해서 내용과 이미지 경로를 채운 뒤 저에게 전달해주시면, 현재 완성된 포트폴리오 구조(HTML/CSS)에 맞춰 새 프로젝트 페이지를 완벽하게 생성해 드립니다!

---

## 1. 기본 정보 (Left Panel)

- **갤러리 썸네일 번호 (Gallery Item Number):** 1번
- **프로젝트명 (Title):** Rolly Product Detail Page
- **프로젝트 설명 (Description):** 신규 브랜드 ‘롤리’의 대표 제품인 바디 롤러 마사지기 상세페이지 외주 작업을 진행했습니다. 브랜드를 처음 접하는 고객들에게 친근하게 다가갈 수 있도록 세련되면서도 위트 있는 무드를 연출하는 데 집중했고, 동시에 제품의 기능적 신뢰감을 주는 데 초점을 맞췄습니다.

기획에 맞는 모델 컷 셀렉부터 피부 및 바디 라인 보정, 상세페이지 레이아웃 디자인, 그리고 카페24 최종 업로드 세팅까지 전 과정을 책임지고 전담했습니다.

- **사용 툴 (Tools):** Photoshop, Premiere Pro
- **작업 연도 (Year):** 2026
- **기여도 (Contribution):** 기여도 90%

## 2. 각 섹션 배경 / 텍스트 컬러 지정 (Right Panel)

**각 섹션의 배경 색상과 텍스트 색상을 지정할 수 있습니다. 배경은 #fff, 텍스트는 #161616**

- **메인 히어로 이미지 영역:** 배경 컬러: #fff
- **뷰 오버 디바이스 영역:** 배경 컬러: #bac76b
- **작업 상세 (Colors & Typography) 영역:** 배경 컬러: #fff / 텍스트 컬러: #161616
- **아트웍 베리에이션 (Artwork Carousel) 영역:** 배경 컬러: #fde38e / 제목 텍스트 컬러: #161616

## 3. 디자인 시스템 (Design System)

### 컬러 (Colors)

**💡 색상 코드는 비워두셔도 됩니다!**
`Hero_Image` 나 `Artwork_Carousel` 폴더에 이미지만 넣어두시면, 제가 인물을 제외하고 가장 많이 쓰인 주조색(약 50%)과 보조색(약 30%) 1~3개를 알아서 추출합니다.
컬러명, RGB, CMYK, HEX, Pantone 값까지 알아서 분석해 채워 넣습니다!

_(만약 꼭 넣고 싶은 컬러가 있다면 아래에 적어주세요)_

- 컬러 1: Sage Green (#BAC76B)
- 컬러 2: Sandy Gold (#FDE38E)
- 컬러 3: Dark Charcoal (#333333)

### 타이포그래피 (Typography)

- **메인 폰트:** Pretendard
- **서브 폰트:** BBH Hegarty _(없으면 생략)_

## 4. 🖼️ 이미지 폴더 안내 (자동 연동)

**💡 이미지 파일명은 마크다운에 적으실 필요가 전혀 없습니다!**
`_source/images/projects/[프로젝트명]` 폴더 내부에 다음처럼 폴더를 만들고 이미지를 넣어주시면 제가 **전부 알아서 찾아서 연동**합니다.

1. `Gallery_Thumbnail` : 메인 화면 갤러리에 들어갈 정사각형/세로/가로 썸네일 이미지 1장
2. `Hero_Image` : 프로젝트 상세창 맨 처음에 나오는 메인 포스터 이미지 1장
3. `View_Over` : 디바이스 목업 안에 들어가서 스크롤될 길쭉한 이미지들 (여러 장 가능)
4. `Artwork_Carousel` : 하단에서 좌우로 스와이프될 아트웍 이미지들 (여러 장 가능)

---

**💡 사용 방법:**
위 내용을 복사한 뒤, 대괄호 `[...]` 안의 내용을 새 프로젝트에 맞게 채워서 채팅창에 붙여넣고 **"이 내용으로 새 프로젝트 페이지 만들어줘"** 라고 말씀해주세요! 구조가 깨지지 않게 완벽히 코드로 변환해 드립니다.
