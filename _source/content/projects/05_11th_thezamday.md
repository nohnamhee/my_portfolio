## 3. 디자인 시스템 (Design System)

*(컬러명과 HEX 코드를 직접 기재해주세요. 제가 나머지 RGB, CMYK, Pantone 값을 알아서 분석해 채워 넣습니다! Pantone 값은 항상 CMYK 아래에 위치하게 됩니다.)*

- 컬러 2: [예: Green Gecko ( #00f600)(PANTONE 802 C)]

### 타이포그래피 (Typography)
*(타이포에 한글이 지원되는 경우, "가 나 다 라 마 바 사 아 자 차 카 타 파 하" 예시를 반드시 포함해 줍니다)*

- **메인 폰트:** [윤고딕 750(영어로표기해줘)]
- **서브 폰트:** [ Gotham]
- **폰트 적용 방식:** *(아래 중 해당하는 것을 선택해주세요)*
  - [ ] **로컬 / Google Fonts** — PC에 설치되어 있거나 Google Fonts에서 제공하는 폰트 (자동으로 연동됩니다)
  - [ ] **Adobe Fonts (Typekit embed)** — 아래 CSS 정보를 함께 기재해주세요
    ```css
    font-family: 폰트명, sans-serif;
    font-style: normal;
    font-variation-settings: "축1" 값, "축2" 값;  /* Variable Font인 경우 */
    ```
    *(Adobe Fonts 웹 프로젝트에서 받은 embed 코드 `<link>` 태그도 함께 알려주시면 `<head>`에 자동 추가됩니다)*

## 4. 🖼️ 이미지 폴더 안내 (자동 연동)
**💡 이미지 파일명은 마크다운에 적으실 필요가 전혀 없습니다!**
`_source/images/projects/[프로젝트명]` 폴더 내부에 다음처럼 폴더를 만들고 이미지를 넣어주시면 제가 **전부 알아서 찾아서 연동**합니다.
1. `Gallery_Thumbnail` : 메인 화면 갤러리에 들어갈 정사각형/세로/가로 썸네일 이미지 1장
2. `Hero_Image` : 프로젝트 상세창 맨 처음에 나오는 메인 포스터 이미지 1장
3. `View_Over` : 디바이스 목업 안에 들어가서 스크롤될 길쭉한 이미지들 (여러 장 가능)
4. `Artwork_Carousel` : 하단에서 좌우로 스와이프될 아트웍 이미지들 (여러 장 가능)

**💡 사용 방법:** 
위 내용을 복사한 뒤, 대괄호 `[...]` 안의 내용을 새 프로젝트에 맞게 채워서 채팅창에 붙여넣고 **"이 내용으로 새 프로젝트 페이지 만들어줘"** 라고 말씀해주세요! 구조가 깨지지 않게 완벽히 코드로 변환해 드립니다.
