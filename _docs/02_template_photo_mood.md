# 새 프로젝트 추가 템플릿 (Contents · BX 전용)

이 양식을 복사해서 내용과 이미지 경로를 채운 뒤 저에게 전달해주시면, 현재 완성된 포트폴리오 구조(HTML/CSS)에 맞춰 새 프로젝트 페이지를 완벽하게 생성해 드립니다!

---

- **카테고리 (Category):** Contents · BX
- **갤러리 썸네일 번호 (Gallery Item Number):** [항상 1번으로 적어주세요. 신규 프로젝트는 1번으로 등록되며 나머지는 자동으로 밀려납니다]
- **프로젝트명 (Title):** [예: 2026 Contents Design]
- **프로젝트 설명 (Description):** [예: 콘텐츠 및 브랜드 경험 디자인을 다룬 프로젝트입니다...]
- **사용 툴 (Tools):** [예: Photoshop, Illustrator]
- **작업 연도 (Year):** [예: 2026]
- **기여도 (Contribution):** [예: 기여도 100%]

- **배경 컬러:** [예: #000000]
- **텍스트 컬러:** [예: #ffffff]
## 3. 🖼️ 이미지 안내 (자동 연동 및 페이징)
이 템플릿의 레이아웃은 **3열 그리드**로 이미지가 여백(2px)만 두고 꽉 채워져 들어가며, 각 이미지 하단에 자동으로 넘버링(01, 02, 03...)이 붙습니다.
이미지가 9장을 넘어갈 경우 하단의 `01 02 03` 탭을 통해 **자동으로 페이지가 나뉘어 페이징**됩니다.

`_source/images/projects/[프로젝트명]` 폴더 내부에 다음처럼 폴더를 만들고 이미지를 넣어주시면 제가 **전부 알아서 찾아서 연동**합니다.
1. `Gallery_Thumbnail` : 메인 화면 갤러리에 들어갈 정사각형/세로/가로 썸네일 이미지 1장
2. `Grid_Images` : 우측 영역에 나열될 이미지들 (제한 없음, 9장마다 자동으로 페이지를 나눕니다)

**💡 사용 방법:** 
위 내용을 복사한 뒤, 대괄호 `[...]` 안의 내용을 채워서 채팅창에 붙여넣고 **"이 내용으로 새 프로젝트 페이지 만들어줘"** 라고 말씀해주세요!
